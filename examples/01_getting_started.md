# Lesson 1: Getting Started with Cono Lua Video API

Welcome to Lesson 1! In this guide, you will learn the fundamentals of using Cono's Lua API to create and render videos programmatically.

---

## Key Concepts

Every video in Cono starts with a **`Model`**. A `Model` represents a scene canvas with:
1. **Dimensions (`Size`)**: Width and height in pixels.
2. **Frame Rate (`FpsTarget`)**: Target frames per second (e.g. 30 FPS or 60 FPS).
3. **Timeline**: A sequence of frames generated by adding components, animating properties, or holding static waiting states.

---

## Step 1: Canvas Dimensions & FPS Selection

Cono provides pre-configured standard video presets via `Size` and `FpsTarget`:

```lua
-- Standard Widescreen HD Video (1920x1080) at 30 FPS
local model = Model.new(Size.youtube_video(), FpsTarget.f30())

-- Vertical Mobile Video (1080x1920) at 60 FPS
local shorts_model = Model.new(Size.youtube_shorts(), FpsTarget.f60())

-- Custom Resolution (800x600) at 24 FPS
local custom_model = Model.new(Size.new(800, 600), FpsTarget.f24())
```

### Available Presets
- `Size.youtube_video()` (1920 x 1080)
- `Size.youtube_shorts()` (1080 x 1920)
- `Size.tiktok()` (1080 x 1920)
- `Size.instagram_reels()` (1080 x 1920)
- `Size.instagram_portrait()` (1080 x 1350)
- `Size.instagram_square()` (1080 x 1080)
- `Size.x_landscape()` (1200 x 675)

---

## Step 2: Creating UI Components

### 1. Creating Text (`Text`)
You can construct text elements with chainable fluent methods:

```lua
local title = Text.new("Cono Engine")
    :size(64)                     -- Font size in pixels
    :color("#FFFFFF")             -- Hex color code
    :font("DejaVu Sans")          -- Optional font family name
    :weight(Weight.bold())        -- Weight.bold(), Weight.medium(), Weight.light(), etc.
    :italic()                     -- Make font italic
```

### 2. Creating Containers (`Container`)
A `Container` wraps a single child component and adds styling like backgrounds, borders, and padding:

```lua
local card = Container.new(title)
    :background("#1E1E2E")        -- Dark background color
    :border_color("#89B4FA")    -- Border accent color
    :border_width(4.0)            -- 4px border width
    :border_radius(16.0)          -- Rounded corners
    :padding(Padding.new(32.0))   -- 32px padding around content
```

---

## Step 3: Adding Components to Model & Holding Timeline

To display static elements on the screen, add them to the model using `add_component()` and hold the frame state for a specified duration using `wait(seconds)`:

```lua
-- Add component to the model root
model:add_component(card)

-- Hold static frame state for 3.0 seconds
model:wait(3.0)
```

---

## Step 4: Exporting Video (`render_video`)

Once you have defined your elements and timeline, render the result to an MP4 video file:

```lua
model:render_video("my_first_video.mp4")
```

---

## Complete Working Example

Save this script as `lesson1.lua`:

```lua
-- 1. Initialize 1080p Video Model @ 30 FPS
local model = Model.new(Size.youtube_video(), FpsTarget.f30())

-- 2. Build Styled Text
local text = Text.new("Hello, Programmatic Video!")
    :size(50)
    :color("#F5E0DC")
    :weight(Weight.bold())

-- 3. Wrap Text inside a Styled Box Container
local box = Container.new(text)
    :background("#11111B")
    :border_color("#F5C2E7")
    :border_width(6.0)
    :border_radius(24.0)
    :padding(Padding.new(40.0))

-- 4. Add Box to Scene Model
model:add_component(box)

-- 5. Hold frame view for 4 seconds
model:wait(4.0)

-- 6. Render MP4 output
model:render_video("lesson1_output.mp4")
print("Video successfully rendered to lesson1_output.mp4!")
```
